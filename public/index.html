      ¿Cómo consigo mis favoritos?
      1. “Me gusta” (likes): en X ve a Configuración → Tu cuenta → Descargar un archivo de tus datos. Cuando llegue (puede tardar 24 h), sube el .zip o sólo data/like.js.
      2. Elementos guardados (bookmarks): el archivo de X no los incluye.
        2. Abre tus guardados en X (x.com/i/bookmarks) y la consola del navegador (Cmd+Opt+J).
        3. Pega el script y pulsa Enter. La primera vez Chrome te pide escribir allow pasting.
        4. Irá bajando sola; al acabar descarga un JSON. Súbelo aquí.
      3. También vale el JSON/CSV de extensiones como twitter-web-exporter.
